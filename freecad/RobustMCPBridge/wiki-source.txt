==Description== <!--T:2-->

<!--T:3-->
The '''Robust MCP Bridge Workbench''' is the server-side connection point that bridges to the [https://pypi.org/project/freecad-robust-mcp/ Robust MCP Server], which enables external applications to control FreeCAD through the [https://modelcontextprotocol.io/ Model Context Protocol (MCP)]. The workbench runs inside FreeCAD and exposes XML-RPC and JSON-RPC interfaces that external MCP clients can connect to.

<!--T:4-->
This workbench is designed to work with the [https://pypi.org/project/freecad-robust-mcp/ Robust MCP Server] (available on PyPI), which allows AI assistants like [https://claude.ai Claude] to interact with FreeCAD through natural language. The full documentation and source code can be found at [https://github.com/spkane/freecad-addon-robust-mcp-server GitHub repository], where you will find the MCP Server, Bridge and some FreeCAD Macros used for various things, not necessarily related to AI or the MCP work.

<!--T:5-->
'''Key Features:'''
* Toolbar controls for starting/stopping the MCP bridge.
* Status indicator showing connection state (green=running, red=stopped).
* XML-RPC server on configurable port (default: 9875).
* JSON-RPC socket server on configurable port (default: 9876).
* Headless mode support for automation and CI/CD pipelines.
* Thread-safe queue system ensuring safe FreeCAD operations.
* Configurable auto-start on FreeCAD launch.

==Installation== <!--T:6-->

===From a source checkout=== <!--T:7-->

<!--T:8-->
The workbench is not currently listed in the public Addon Manager. From a matching source checkout, run {{incode|just install::mcp-bridge-workbench}} and restart FreeCAD. The installer selects the latest versioned profile when present and installs to {{FileName|Mod/RobustMCPBridge/freecad/RobustMCPBridge/}}. Pair the server and bridge with {{incode|uv run freecad-mcp --pair-bridge}} as the FreeCAD user before starting the bridge. See the [https://spkane.github.io/freecad-addon-robust-mcp-server/latest/getting-started/installation/ installation and pairing guide].

===Manual installation=== <!--T:9-->

<!--T:10-->
Download a pairing-capable workbench archive matching your server from the [https://github.com/spkane/freecad-addon-robust-mcp-server/releases?q=robust-mcp-workbench&expanded=true workbench releases], extract its top-level package directory into your selected FreeCAD profile's {{FileName|Mod}} directory, and restart FreeCAD. The archive contains {{FileName|package.xml}} and {{FileName|freecad/RobustMCPBridge/}}.

==Usage== <!--T:12-->

===GUI mode=== <!--T:13-->

<!--T:14-->
[[Image:Addon_RobustMCPBridge_toolbar.png|Robust MCP Bridge workbench toolbar]]

<!--T:15-->
# Switch to the '''Robust MCP Bridge''' workbench using the workbench selector
# Click {{Button|Start Bridge}} in the toolbar
# The status indicator turns green when running
# External MCP clients can now connect to localhost:9875 (XML-RPC) or localhost:9876 (Socket)

<!--T:16-->
To stop the bridge, click {{Button|Stop Bridge}} in the toolbar.

<!--T:17-->
[[Image:Addon_RobustMCPBridge_statusbar.png|Robust MCP Bridge workbench statusbar]]

===Headless mode=== <!--T:18-->

<!--T:19-->
For automation and CI/CD pipelines, pair the bridge first as described in the [https://spkane.github.io/freecad-addon-robust-mcp-server/latest/getting-started/installation/ installation and pairing guide], then run it without the GUI. These paths assume a source installation in an unversioned profile; use the actual profile and archive directory if different. On Linux use {{incode|FreeCADCmd}} if that is the installed executable:

<!--T:20-->
'''Linux:'''
</translate>
{{Code|code=
freecadcmd ~/.local/share/FreeCAD/Mod/RobustMCPBridge/freecad/RobustMCPBridge/freecad_mcp_bridge/blocking_bridge.py
}}
<translate>

<!--T:19-->
'''macOS:'''

</translate>
{{Code|code=
/Applications/FreeCAD.app/Contents/Resources/bin/freecadcmd \
    ~/Library/Application\ Support/FreeCAD/Mod/RobustMCPBridge/freecad/RobustMCPBridge/freecad_mcp_bridge/blocking_bridge.py
}}
<translate>

<!--T:22-->
The bridge will start and keep FreeCAD running until you press Ctrl+C.

==Connecting MCP clients== <!--T:29-->

<!--T:30-->
The workbench provides the bridge used by the Robust MCP Server. Install matching pairing-capable server and workbench builds from the same source checkout; see the [https://spkane.github.io/freecad-addon-robust-mcp-server/latest/getting-started/installation/ installation guide]. Run the pairing command as the FreeCAD user:

</translate>
{{Code|code=
uv run freecad-mcp --pair-bridge
}}
<translate>

<!--T:32-->
See the [https://github.com/spkane/freecad-addon-robust-mcp-server GitHub repository] for full documentation on configuring MCP clients.

==Troubleshooting== <!--T:33-->

===Bridge won't start=== <!--T:34-->

<!--T:35-->
# Check the FreeCAD Python console ({{MenuCommand|View → Panels → Python console}}) for error messages.
# Ensure no other process is using ports 9875/9876.
# Try restarting FreeCAD.

===Connection refused=== <!--T:36-->

<!--T:37-->
# Verify the bridge is running (green status indicator in toolbar).
# Check that ports match between the workbench preferences and your MCP client configuration.
# If connecting from Docker, use {{incode|host.docker.internal}} instead of {{incode|localhost}}.

===Headless mode won't start=== <!--T:38-->

<!--T:39-->
# Ensure you're using {{incode|freecadcmd}} (not {{incode|freecad}}).
# Verify the script path is correct for your installation.
# Test FreeCAD first: {{incode|freecadcmd -c "print('test')"}}.
